# 项目协作交互原型

基于“分析详情”截图制作的可点击演示，打开 `index.html`，点击“项目协作”进入成员管理。也可从顶部“我的项目”进入项目列表。

- “添加成员”输入手机号后会自动显示匹配的云平台账号，点击“确认云平台账号”进入角色选择；确认时会提示核对账号及授权影响。演示手机号：`13800000005`，自动匹配 `xia.laoshi`（夏老师）。核对失败时使用统一提示。
- 验证弹窗中的“编辑提示语”可以修改弹窗说明、确认时的安全提示和核对失败提示；文案与成员、角色等演示改动分别保存在当前浏览器的本地存储中。默认文案集中在 `script.js` 的 `defaultAccountCopy`，可直接改代码后发布新版。
- 截图、项目编号、手机号及账号都是演示数据。前端匹配不构成真实身份认证；按手机号自动回显账号在真实系统中可能泄露账号信息。正式接入须由服务端完成身份核验，并在回显前落实授权、信息脱敏、限流与访问记录。此原型不会影响真实云平台。
