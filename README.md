# 项目协作交互原型

基于“分析详情”截图制作的可点击演示。打开 `index.html` 就是项目协作成员表格，可从上方“项目数据”切回参考页面，也可从顶部“我的项目”进入项目列表。

- “添加成员”输入手机号后会自动显示匹配的云平台账号；点击“确认云平台账号”后，带提示图标的安全提醒会以与弹窗相同的宽度及圆角短暂浮现在上方，然后自动进入角色选择弹窗。演示手机号：`13800000005`，自动匹配 `xia.laoshi`（夏老师）。核对失败时使用统一提示。
- 角色选择卡片使用三种不同图标：管理员为盾牌、成员为人物、访问者为眼睛；图标只用于辅助识别，选择仍由单选按钮控制。
- 两个示例项目的成员表格默认都直接显示技术支持（固定管理员）及陈老师、小李、小周、林老师五行。表格保留固定高度，移除成员后不会收缩，添加更多成员后可在表格内滚动。技术支持的“调整角色”置灰且不可点击，但可以移除；其他四位均可调整角色和移除。技术支持被移除后不会自动重新出现，重新添加时仍固定为管理员。
- 此次调整默认入口和表格后启用了新的浏览器本地存储键；旧版演示记录仍保留在浏览器中，但不会覆盖新默认名单。新版中的成员、角色和移除操作仍保存在当前浏览器。提示语不在页面中提供编辑入口，可在 `script.js` 中修改后重新发布。
- 成员和权限表格正文为黑色、14px；角色标签按背景色使用对应的深色文字，调整角色为蓝色，移除为红色。
- 截图、项目编号、手机号及账号都是演示数据。前端匹配不构成真实身份认证；按手机号自动回显账号在真实系统中可能泄露账号信息。正式接入须由服务端完成身份核验，并在回显前落实授权、信息脱敏、限流与访问记录。此原型不会影响真实云平台。
