# 项目协作交互原型

基于“分析详情”截图制作的可点击演示，打开 `index.html`，点击“项目协作”进入成员管理。也可从顶部“我的项目”进入项目列表。

- “添加成员”先手动输入手机号及云平台账号，再点击“确认云平台账号”，通过后选择角色并添加。演示组合：`13800000005` / `xia.laoshi`（夏老师）。不根据手机号自动显示账号；不匹配时使用统一提示，不区分“手机号不存在”或“账号错误”。
- 验证弹窗中的“编辑提示语”可以修改弹窗说明、安全提示和核对失败提示；文案与成员、角色等演示改动分别保存在当前浏览器的本地存储中。默认文案集中在 `script.js` 的 `defaultAccountCopy`，可直接改代码后发布新版。
- 截图、项目编号、手机号及账号都是演示数据。前端匹配不构成真实身份认证；正式接入须由服务端执行账号核验、权限控制、访问记录与防枚举/限流策略。此原型不会影响真实云平台。
